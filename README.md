# kairos-assets

Public brand assets (logo, favicon) for **Kairos Operations** and **Kairos Workforce**.

This repo is intentionally public so browsers can load these images directly via
`raw.githubusercontent.com` (favicon links, `<img>` tags) without needing Google Drive
sharing permissions, which have proven unreliable across users/orgs.

## Scope — images only

This repo exists **only** to host non-sensitive brand images (logos, favicons). Do not
commit anything else here — no app code, no internal docs, no screenshots, no config,
no credentials. Keep it narrow.

## Usage

Reference a file with its raw content URL:

```
https://raw.githubusercontent.com/isopropylMigs/kairos-assets/main/<filename>
```
